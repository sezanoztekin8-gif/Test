# Retention, hooks and structure

## Beat types (tag every beat of a breakdown or script with one)

| Beat | What it does |
|---|---|
| Hook | stops the scroll/click-away; confirms the click was right |
| Promise | states what the viewer will get by the end |
| Stakes | why it matters to the viewer; what is lost or gained |
| Open loop | raises a question answered later |
| Context | the minimum background needed |
| Proof | evidence, demonstration, example, source |
| Re-hook | renews interest before a likely drop ("but that's not the strangest part") |
| Mini-payoff | delivers a small reward to keep momentum |
| Twist | changes the viewer's expectation |
| Payoff | delivers the main promise |
| CTA | asks for the next action (next video, subscribe, comment) |

Name beats by what they do, not by their topic.

## Hook patterns (first 5-30 seconds)

- **Result first**: show the end result or most dramatic moment, then rewind.
- **Bold claim + proof teaser**: a surprising statement and a hint you'll prove it.
- **Question the viewer already has** (from the title), then a promise to answer it.
- **Cold open**: start in the middle of the action or story, no intro.
- **Contrast**: what everyone believes vs what's true.
- **Stakes**: what the viewer loses by not knowing this.
- **Story in motion**: a character, a goal and an obstacle in two sentences.

Rules: match the title/thumbnail promise within seconds; no logo intros, long
greetings or "before we start" asides; show, don't describe, when visuals allow;
cut every word that delays the promise.

## Structure

- Long-form: a re-hook or mini-payoff roughly every 60-90 seconds; the main
  payoff late but before the outro; end screens in the last 5-20 seconds.
- Story videos: setup -> inciting moment -> rising tension (with open loops) ->
  climax -> resolution -> meaning/lesson -> next story.
- Explainers/lists: promise -> items in order of interest (strong first, strongest
  near the end) -> recap -> next video.
- Change something every few seconds in fast niches (angle, visual, sound, text);
  slower, calmer pacing can suit relaxing or deep-dive niches. Match the niche.

## Reading a retention curve

| Shape | Likely cause | Fix |
|---|---|---|
| Sharp drop in first 30s | hook doesn't match packaging, slow start | open with the promise; cut the intro |
| Steady downward slope | pacing, repetition | tighten, add re-hooks, more visual change |
| Sudden cliff mid-video | a dull segment, off-topic tangent, sponsor read | trim/move it; re-hook before it |
| Bump/spike | rewatched moment | make more of that; clip it into a Short |
| Drop before the end | viewers sense the end (recap, outro) | end sooner; tease the next video earlier |

Average view percentage naturally falls as videos get longer; compare videos of
similar length, and use `relativeRetentionPerformance` when available.
